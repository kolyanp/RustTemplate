# Команди та Привілеї плагіна MonumentTransit

## Для гравців

Гравцям зазвичай не потрібно вводити команди вручну. Взаємодія з плагіном відбувається шляхом наближення до терміналу та натискання клавіші взаємодії (E), що відкриває графічний інтерфейс (UI) вибору точки призначення.

**Консольні команди гравця (викликаються автоматично через UI):**
- `monumenttransit.closeui` — закриває UI меню телепортації.
- `monumenttransit.pay <destinationId> <terminalId>` — ініціює оплату та телепортацію до вибраної точки.

---

## Для адміністраторів

Для керування мережею терміналів адміністратори можуть використовувати спеціальне меню. 
**Вимога:** наявність привілею `monumenttransit.admin`.

**Чат-команди:**
- `/tterminal` — відкриває графічне меню адміністратора (Admin UI) для налаштування системи.

**Консольні команди адміністратора (також доступні через кнопки в Admin UI):**
- `monumenttransit.admin.close` — закриває UI меню адміністратора.
- `monumenttransit.admin.createnpc` — створює термінал у вигляді NPC на вашій поточній позиції та з вашим напрямком погляду.
- `monumenttransit.admin.createprop` — створює термінал у вигляді об'єкта (Prop, за замовчуванням торговий автомат) на вашій поточній позиції.
- `monumenttransit.admin.createdest` — створює нову точку призначення (Destination) на вашій поточній позиції для майбутніх телепортацій.

---

## Привілеї (Permissions)

- `monumenttransit.use` — базовий дозвіл на використання системи телепортації. Можна призначити для групи `default`, щоб усі гравці мали доступ.
- `monumenttransit.admin` — дозвіл на адміністрування, створення терміналів, точок призначення та використання команди `/tterminal`.
- `monumenttransit.discount.<відсоток>` — надає відсоткову знижку на вартість телепортації. (Наприклад, `monumenttransit.discount.25` надасть гравцеві знижку 25%).
